## 3. Step 1 — Install PostgreSQL

Kong needs PostgreSQL to store its configuration (services, routes, plugins, consumers).

```bash
# Install PostgreSQL
sudo apt-get update
sudo apt-get install -y postgresql postgresql-contrib

# Start and enable it
sudo systemctl start postgresql
sudo systemctl enable postgresql

sudo systemctl status postgresql

# Create the Kong database user and database
sudo -u postgres psql 

-- Create a user for Kong
CREATE USER kong WITH PASSWORD 'opstree@123';

-- Create the database owned by that user
CREATE DATABASE kong OWNER kong;

-- Give full privileges
GRANT ALL PRIVILEGES ON DATABASE kong TO kong;

# Test that Kong user can connect
psql -h 127.0.0.1 -U kong -d kong -c "SELECT version();"
```

## 5. Step 3 — Configure kong.conf

Now edit the main config file. First copy the default template:

```bash
sudo cp /etc/kong/kong.conf.default /etc/kong/kong.conf

# Open it
sudo nano /etc/kong/kong.conf
```

Find each of these lines (use Ctrl+W to search in nano), uncomment them (remove the `#`), and set the values:

```ini
# Search for: database
database = postgres

# Search for: pg_host
pg_host = 127.0.0.1

# Search for: pg_port
pg_port = 5432

# Search for: pg_database
pg_database = kong

# Search for: pg_user
pg_user = kong

# Search for: pg_password
pg_password = kong_strong_password_change_me

# Search for: proxy_listen
proxy_listen = 0.0.0.0:8000, 0.0.0.0:8443 ssl

# Search for: admin_listen
# IMPORTANT: keep this on 127.0.0.1, never 0.0.0.0 in production
admin_listen = 127.0.0.1:8001

# Search for: status_listen
status_listen = 0.0.0.0:8100

# Search for: proxy_access_log
proxy_access_log = /usr/local/kong/logs/access.log

# Search for: proxy_error_log
proxy_error_log = /usr/local/kong/logs/error.log

# Search for: log_level
log_level = notice

# Search for: nginx_worker_processes
nginx_worker_processes = auto

# Search for: mem_cache_size
mem_cache_size = 256m

admin_gui_listen = 0.0.0.0:8002
```

```bash
